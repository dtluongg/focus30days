----

- In string, we can add or append by (+=) operator. 
- example:
    let greeting = 'hello';
    greeting += ', my name is Luong'
    console.log(greeting) // hello, my name is Luong
    

- We have two options for expand string. 
1. same example above.
2. use concat() function. 
- example: 
    let str1 = 'Luong'
    let str2 = 'Do Tien'
    let result = str1.concat(' ', str2);
    console.log(result) // 'Luong Do Tien'

- Why is console.log() helpful when building out web applications?
-> It is commonly used by developers for debugging and inspecting values or expressions in their code during development.
