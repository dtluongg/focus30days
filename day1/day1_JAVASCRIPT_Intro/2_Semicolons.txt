JS have ASI (Automatic Semicolons Insertions)
JS auto complete line code with semicolons (;), but we need attention at object, or return.
Because JS auto complete semicolons after enter complete line.
If we use:
    ex:
        return 
        {
            value = "abc"
        };
    JS will be know like is:
        return;
        {
            value = "abc"
        };

    =>>> Undefind.

    ex:
    (function() {

    })();
